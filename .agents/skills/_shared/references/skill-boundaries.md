# Skill Boundaries

| Skill | Owns | Hands off |
|---|---|---|
| `experiment-planner` | hypotheses, baselines, ablations, expected Evidence | confirmed design to Registry |
| `experiment-registry` | IDs and provenance metadata | confirmed records to Analysis/Audit |
| `result-analysis` | statistics and table/figure proposals | findings to Audit |
| `experiment-audit` | completeness, fairness, reproducibility, leakage risks | audited Evidence to Claim–Evidence |
| `claim-evidence` | Claim–Evidence traceability | approved matrix to paper writing |
| `number-consistency-audit` | cross-location numeric consistency | discrepancy report to revision |
| `gaps-research-orchestrator` | stage, largest Evidence Gap, next Skill | routes only |

Paper prose belongs to `research-writing-skill`; citation truth/entailment belongs to a future citation audit. Experiment execution is outside these seven Skills.
