# Routing error propagation analysis

Canonical ALL S_ALL/S_CC/oracle RMSE = 13.3144/10.8148/11.0561 ppm. The defined routing gap is 2.4996 ppm and the defined oracle gap is -0.2413 ppm. S_CC is a selected route-correct population, whereas oracle uses all windows; therefore the gap is descriptive propagation evidence rather than a controlled causal effect.
