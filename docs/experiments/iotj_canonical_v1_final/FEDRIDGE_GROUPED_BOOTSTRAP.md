# FedRidge raw-file-grouped bootstrap

Using 5,000 paired raw-file-group bootstrap replicates (seed 20260809), overall DeltaRMSE = RMSE84-RMSE83 = -0.5350 ppm, 95% percentile CI [-1.4579, 0.4262]. Windows were never treated as independent bootstrap units. C4 degradation and every per-target/per-gas interval remain in the CSV.
