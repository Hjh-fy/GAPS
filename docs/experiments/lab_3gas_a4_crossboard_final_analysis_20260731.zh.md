# 实验室三气体 A4 跨板分类正式结果汇总（seed 42）

## 1. 结论摘要

本轮在 A4 协议下完成了 P2→P1、P1→P3 和 P1+P2→P3 三组精简跨板实验，并将原有 P2→P3 结果纳入统一审计。四组实验均使用固定第 25 轮适配模型；主指标仍为目标板稳定段 360 个窗口的三气体分类结果，0–150 s 早期 60 个窗口和完整 420 个窗口仅作为冻结模型的事后诊断。

在当前唯一种子 42 下，原有 P2→P3 仍是 P3 目标域上表现最好的配置：稳定段 Accuracy 为 99.72%（359/360），Macro-F1 为 99.72%；加入早期窗口后，完整范围 Accuracy 为 95.24%（400/420），但早期窗口单独只有 68.33%（41/60）。这说明稳定段分类能力很强，而通气后 0–150 s 的动态响应仍是主要瓶颈。

P1→P3 的稳定段 Accuracy 为 98.33%，略高于 P1+P2→P3 的 98.06%。因此，本轮没有观察到增加 P1 源板后对 P3 的增益。由于 P1+P2 使用了更多源域样本且没有匹配训练预算控制，这一结果只能描述为“当前配置未增益”，不能解释为多源训练本身无效。P2→P1 的目标板不同，不能与三组 P3 结果直接作优劣排名。

## 2. 实验口径

| 项目 | 固定设置 |
|---|---|
| 任务 | 乙醛、甲烷、乙酸三分类 |
| 输入 | 相对电阻时序，形状 100×6 |
| 通道 | CH1、CH2、CH4、CH6、CH8、CH9 |
| 模型配置 | `proto_replay` |
| 域适配 | `corrected_b2`，目标监督权重为 0 |
| 联邦训练 | 25 轮，每客户端本地 3 轮 |
| 模型选择 | 固定最后一轮，即 round 25 |
| 随机种子 | 42 |
| 归一化 | 仅使用相应源域训练数据拟合 |
| 目标校准 | 覆盖全部保留浓度的校准样本 |
| 主测试范围 | 稳定段 360 窗口 |
| 诊断范围 | 0–150 s 早期 60 窗口；完整 420 窗口 |

各方向仅更换源板与目标板，训练轮数、模型、域适配、目标校准、检查点选择和评估器保持一致。P1+P2→P3 使用两个源客户端，其训练样本量与单源方向不相同。

## 3. 固定第 25 轮分类结果

### 3.1 窗口级结果

| 方向 | 稳定段 360：正确率 / Macro-F1 | 早期 60：正确率 / Macro-F1 | 完整 420：正确率 / Macro-F1 |
|---|---:|---:|---:|
| P2→P3（原 A4） | 359/360，99.72% / 99.72% | 41/60，68.33% / 58.31% | 400/420，95.24% / 95.17% |
| P2→P1 | 352/360，97.78% / 97.77% | 25/60，41.67% / 33.77% | 377/420，89.76% / 89.68% |
| P1→P3 | 354/360，98.33% / 98.33% | 32/60，53.33% / 52.21% | 386/420，91.90% / 91.96% |
| P1+P2→P3 | 353/360，98.06% / 98.05% | 17/60，28.33% / 28.02% | 370/420，88.10% / 88.10% |

### 3.2 暴露级结果

稳定段和完整范围中，四组模型的暴露级 Accuracy 均为 100%（30/30）。这里的“暴露级”表示将同一次气体暴露内的多个窗口聚合后再判断类别，并不代表该暴露中的每个时间窗口都预测正确。

早期范围的暴露级结果更能反映动态阶段的困难：

| 方向 | 早期暴露级正确数 | 早期暴露级 Accuracy |
|---|---:|---:|
| P2→P3（原 A4） | 20/30 | 66.67% |
| P2→P1 | 14/30 | 46.67% |
| P1→P3 | 18/30 | 60.00% |
| P1+P2→P3 | 13/30 | 43.33% |

完整范围的 30/30 主要受每次暴露中数量更多、分类更可靠的稳定段窗口支撑，不能据此认为早期检测已经可靠。

## 4. 域适配前后稳定段结果

| 方向 | 未适配 Accuracy | 适配后 Accuracy | 变化 | 正确窗口变化 |
|---|---:|---:|---:|---:|
| P2→P3（原 A4） | 94.72% | 99.72% | +5.00 个百分点 | +18 |
| P2→P1 | 98.61% | 97.78% | −0.83 个百分点 | −3 |
| P1→P3 | 98.89% | 98.33% | −0.56 个百分点 | −2 |
| P1+P2→P3 | 97.50% | 98.06% | +0.56 个百分点 | +2 |

适配的收益具有明显方向依赖性。P2→P3 获得了显著的描述性增益，P1+P2→P3 获得小幅增益，而 P2→P1、P1→P3 在本种子上略有下降。因此，不能仅凭 P2→P3 推断该适配方法在所有板间方向都必然提升。

## 5. 同一 P3 目标域的描述性比较

以 P2→P3 为参照：

| 方向 | 稳定段 Accuracy 差值 | 早期 Accuracy 差值 | 完整 Accuracy 差值 |
|---|---:|---:|---:|
| P1→P3 | −1.39 个百分点（−5 窗口） | −15.00 个百分点（−9 窗口） | −3.33 个百分点（−14 窗口） |
| P1+P2→P3 | −1.67 个百分点（−6 窗口） | −40.00 个百分点（−24 窗口） | −7.14 个百分点（−30 窗口） |

在当前固定配置和 seed 42 下，P2 是比 P1 更适合 P3 的源板；直接合并 P1、P2 没有继续提高 P3 性能。该结论是本轮配置下的描述性观察，不是统计显著性结论，也不能排除通过源板加权、客户端平衡或匹配训练预算后获得不同结果。

## 6. 错误模式

稳定段错误很少：P2→P3 仅有 1 个乙酸窗口被判为乙醛；P2→P1 的 8 个错误主要发生在甲烷与乙酸之间；P1→P3 和 P1+P2→P3 的少量错误主要涉及乙醛与另外两类的混淆。

早期窗口的错误更集中且具有方向差异：

- P2→P3：20 个乙酸早期窗口中有 17 个被判为甲烷，乙醛和甲烷早期窗口则全部正确。
- P2→P1：20 个甲烷早期窗口中有 19 个被判为乙醛，乙酸也存在明显混淆。
- P1→P3：20 个甲烷早期窗口中有 17 个被判为乙酸。
- P1+P2→P3：三类早期窗口均出现较大范围混淆，而不是单一类别失效。

这表明早期困难不仅来自统一的低信号幅度，还受到板间动态响应形状和源域组合方式影响。后续若要改善实时首段识别，应将早期动态窗口作为单独训练目标，而不是只依赖稳定段模型外推。

## 7. 可报告结论与边界

当前证据支持以下表述：

1. 在全保留浓度参与目标校准、固定第 25 轮和 seed 42 的 A4 协议下，P2→P3 的稳定段三气体分类 Accuracy 为 99.72%，完整范围 Accuracy 为 95.24%。
2. 四个方向的稳定段 Accuracy 均达到 97.78% 以上，但早期窗口 Accuracy 仅为 28.33%–68.33%，早期动态响应是主要性能瓶颈。
3. 在三组同目标 P3 的实验中，P2→P3 优于 P1→P3 和 P1+P2→P3；本轮未观察到简单增加 P1 源板带来的增益。

当前证据不支持以下更强表述：

- 不支持声称结果已对随机种子稳定，因为本轮只有 seed 42。
- 不支持统计显著性、置信区间或总体方差结论；重叠窗口不能视为相互独立的重复样本。
- 不支持未见浓度泛化结论，因为目标校准覆盖了全部保留浓度。
- 不支持早期实时可靠性结论，因为早期评估是冻结稳定段模型后的事后诊断，且性能明显下降。
- 不支持“多源一定更差”或“源板多样性无效”的因果结论，因为 P1+P2 没有匹配单源训练预算。

## 8. 后续建议

优先级最高的是针对早期动态段进行独立建模和验证，例如加入时间位置编码、稳定段/动态段双头分类或为早期窗口设置单独损失权重。其次可在不扩大实验复杂度的前提下补充 3–5 个随机种子，以确认 P3 三个源域配置之间 1–2 个百分点的差异是否稳定。若要研究多源价值，应增加与 P1+P2 相同样本预算的 P2 单源控制组，并显式比较客户端等权和样本量加权。
