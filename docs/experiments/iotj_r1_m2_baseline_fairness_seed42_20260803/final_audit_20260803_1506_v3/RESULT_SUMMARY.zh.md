## 对论文主张的影响

- 可以支持：目标辅助适配对 C5 跨设备迁移非常关键；B5 明显优于无目标信息的 Source-only/FedProx，并优于 DS 校准迁移基线。
- 不能支持：当前 seed42 结果不能宣称 GAPS 的客户端对齐、回放、解耦或选择性聚合优于“FedAvg + 相同目标适配”。后者的 Macro-F1 比 B5 高 1.022 个百分点，因此原先宽泛的机制优越性表述必须收窄。
- Target-only 使用全部 320 个 C5 校准标签进行 2,500 次监督 CE 更新，属于更强的目标监督上界/参考，不是与 B5 等目标的公平消融。
- 仅完成 seed42，不能报告稳定性、置信区间、显著性或跨种子优势。
