# 83D / 91D / 104D 特征消融实验审计

## 审计裁决

**有限批准（limited approval）。** 本实验可作为以下窄主张的证据：在冻结的 C5 数据、冻结分类路由、冻结 H1 和相同 Ridge 校准协议下，从当前104字段接口中删除21个常数辅助字段，不改变五种子 S_CC 性能。

以下主张被阻断，不能由本实验支持：

- “完整104D包含并利用了21维有信息量的协议元数据”；
- “8维在线安全元数据保留了完整元数据的性能”；
- “元数据在部署时带来额外泛化能力”。

阻断原因不是结果不显著，而是正式数据中这些字段缺失或恒定，导致三组有效设计矩阵相同。

## 审计范围与证据链

- 计划与矩阵在运行前写入独立目录，三组定义、种子、指标、alpha 网格和判定门槛均已冻结。
- 分类器、五种子分类路由、源 H1、数据划分和 QC 均复用原正式资产，没有重新训练或修改。
- 每个种子/气体/变体只使用 calibration 内部的 60/20 划分选择 alpha；全部选择写入 `calibration_selection_lock.json` 后才评估 test。
- 运行产物包含逐种子、逐气体、汇总、配对差异、协议清单、依赖清单和 SHA-256 索引。
- 新增测试覆盖特征集合互斥/包含关系、在线安全排除项和常数元数据下的预测等价性；兼容既有五种子评估测试。

## 主要发现

### A1：104D 是模式维数，不是当前数据的有效维数（阻断性）

C5 experiment-info 仅保留设备、气体、浓度、重复、文件名、统一的 late phase 标签及分类/回归标签；窗口时间与响应阶段字段没有进入该冻结资产。缺失字段经构造器默认化后，21个辅助列全部成为常数。带截距 Ridge 中，常数列不会提供样本间辨识信息。因此当前 M83、M91、M104 不是三个信息量不同的处理条件。

影响：可审计“移除常数占位列的等价性”，不可审计“元数据价值”或“因果安全元数据替代完整元数据”。

### A2：五种子不是五个独立物理重复（非阻断但限制外推）

五个种子改变分类器训练/路由随机性，但共享同一 C5 窗口级数据资产。描述性均值、SD 和 t 区间可用于算法随机性稳定性，不应解释为跨设备、跨采集批次的总体置信区间。

### A3：窗口级划分允许原文件重叠（对物理泛化主张阻断）

该问题是冻结正式协议的既有限制，而非本消融新增。它不妨碍在同一协议内比较三种列集合，但会阻断“未见物理采集文件上的泛化”之类强主张。若论文需要该主张，应补文件级或采集批次级隔离实验。

## 可用于论文的证据边界

批准：

> Under the frozen target protocol, removing the 21 non-varying auxiliary schema fields left five-seed regression performance unchanged; the effective target representation was therefore the 83-dimensional sensor-statistics vector (84 dimensions when the frozen H1 prior was appended).

不批准：

> Online-safe metadata matched the predictive utility of full protocol metadata.

第二句要求重建包含真实、因果可用且具有变化性的8维字段的数据集后重新运行。

## 后续修复优先级

1. 立即修订论文的输入维数与元数据描述，优先采用“83D传感统计；最终模型追加 H1 为84D”的有效维数表述。
2. 若研究问题确实要求元数据贡献，重建带窗口级因果字段的数据资产，并增加运行前的列存在性、缺失率、唯一值数和按气体方差门禁。
3. 对重建数据重新执行三组五种子消融，禁止沿用本次的“等效通过”作为真实元数据的证据。
4. 在更强的泛化主张前，补充按原始文件/采集批次隔离的验证。
