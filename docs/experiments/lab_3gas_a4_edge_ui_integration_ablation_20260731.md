# A4 稳定段上位机接入最小消融计划

## 原则

所有消融只用于定位接入误差，不重新声明 A4 泛化准确率。每次只改变一个
因素；主协议始终是“严格 1 Hz + 300 s 中位数 R0 + 相对电阻 + 居中反射
MA5 + 100/50 窗口 + P2-only z-score + 窗口起点不早于 250 s”。

## ABL-PRE-01：基线统计量

- 主协议：逐通道中位数；
- 诊断变体：逐通道均值；
- 目的：证明当前 UI 旧均值实现不能等价复现训练输入；
- 指标：首个分歧窗口、输入最大绝对差、预测类别变化数；
- 结论边界：不得因均值偶然准确而替换冻结协议。

## ABL-PRE-02：滤波相位

- 主协议：居中反射 MA5，在线延迟 2 s；
- 诊断变体：因果 MA5；
- 目的：量化为了“零未来样本”造成的训练/部署偏移；
- 指标：输入最大绝对差、类别变化数、概率 KL/绝对差；
- 进入正式协议条件：只有重新训练并在独立 P3 测试上验证后，因果滤波才可
  替换主协议。

## ABL-PRE-03：稳定段门控

- 主协议：窗口起点 `>=250 s`；
- 诊断变体：窗口起点 `>=150 s`；
- 参考全时段：不设稳定门控；
- 目的：区分模型本身与覆盖范围带来的准确率变化；
- 必报：正确数/总数、Macro-F1、覆盖率、每个时间位置混淆；
- 禁止：只报告最高准确率而不报告覆盖率。

## ABL-PRE-04：物理输入域

- 主协议：真实电阻值；
- 诊断变体：原始 ADC、单一负载电阻换算、相对电导；
- 目的：在硬件合同确认后验证物理域映射；
- 前置条件：六通道真实负载电阻和通道映射已冻结；
- 未满足前置条件时状态保持 blocked，不运行该消融。

## ABL-OUT-01：窗口结果与累计共识

- 窗口结果：当前 100 s 窗口 softmax argmax；
- 累计共识：当前暴露段所有有效窗口 softmax 算术平均后的 argmax；
- 目的：观察累计共识是否减少偶发窗口抖动；
- 指标：窗口准确率、暴露级准确率、首次稳定正确时间、类别翻转次数；
- 限制：不从 P3 test 标签调节共识阈值。

## 决策规则

1. 模型或预处理 parity 不通过，不进入 UI；
2. Runtime v5 回归失败，不发布实验室模式；
3. A4 稳定门控外不产生预测；
4. 硬件输入域未冻结，不宣称完成真实在线三气体识别；
5. 所有结果必须绑定模型、归一化、代码和输入数据 SHA256。
