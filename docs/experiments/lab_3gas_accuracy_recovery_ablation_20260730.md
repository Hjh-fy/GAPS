# 实验室三气体准确率恢复：消融对照定义

## 核心原则

本消融只回答 P2 → P3 全浓度三分类问题，不采用五折。每一组只改变一个因素，避免把预处理、域适配、通道和时间范围同时改变后无法归因。

## 单因素对照

| 对照 | 唯一改变 | 主要回答的问题 |
|---|---|---|
| REC-A0 → REC-A1 | legacy strong DA → corrected B2 DA | 旧域适配组合是否导致负迁移或不稳定 |
| REC-A1 → REC-A2 | `lambda_target_ce: 0 → 1.0` | 少量目标标注监督能否减少甲烷→乙酸错误 |
| REC-A1 → REC-A3 | 相对电阻 → 原始电阻计算的精确相对电导 | 特征物理定义不一致是否是主要性能瓶颈 |
| REC-A1 → REC-A4 | 0–1200 s → 150–1200 s | 早期进气瞬态对窗口级准确率的贡献 |
| REC-A1 → REC-A5 | 6 通道 → 去除 CH2 的 5 通道 | CH2 的板间漂移是否造成负贡献 |

## 固定项

- 数据方向：P2 → P3。
- 三种气体、全保留浓度、相同 exposure 集合。
- 25 轮联邦训练、每轮本地 3 epoch、batch size 32。
- seed 42 用于单因素筛选。
- 不做浓度回归，不做五折。
- 归一化统计量只由 P2 train 计算。
- checkpoint 固定使用第 25 轮作主比较；旧基线第 2 轮仅作为 checkpoint 选择诊断。

## 校准内选择协议

P3 calibration 每次 exposure 的三个窗口按基础时间索引固定拆分：

- 索引 3、11：用于 DA-fit；
- 索引 19：用于 config-validation。

config-validation 只用于判断单因素是否晋级，不使用 P3 test 调参。由于 P3 test 已在前期分析中被查看，本轮最终 test 仍只能视为探索性证据。

## 早期瞬态对照的特殊报告

REC-A4 必须同时给出：

1. 完整 420 窗口上的结果；
2. 与稳定段一致的共同测试范围结果；
3. 覆盖窗口数与覆盖率；
4. 最早可判定时间。

固定排除索引 0、1 后，保留 360/420 个测试窗口，覆盖率为 85.71%。
被排除窗口为 0–100 s 和 50–150 s。由于 150–250 s 是目标校准窗口，
且其相邻重叠窗口已被 purge，独立 test 中第一个保留窗口为 250–350 s。
这不等于部署系统必须等待 250 s，而是当前无泄漏测试协议能够独立评估
的最早稳定窗口。不能将稳定段准确率与完整时间范围准确率等价比较。

## 组合候选规则

只有在 config-validation 上满足以下条件的因素才能进入 REC-A6：

- Macro-F1 相对 REC-A1 至少提升 0.02；
- 每类 recall 均不低于 0.90；
- 暴露级 accuracy 不下降；
- 数据与预处理 QC 通过。

组合实验按已验证因素构建，不再增加未注册的通道组合、时间阈值或损失权重。最终内部稳定性使用 seed 42、43、44；随后必须用新日期或独立重复采集数据确认。

## 结果解释边界

- 诊断性线性分类器用于定位问题，不代表 GAPS 正式模型性能。
- 公共数据 98–99% 与实验室 91.90% 的数据量、目标划分难度、预处理和 DA 设置不同，不能直接归因为模型退化。
- 若去除早期窗口后准确率提高，只能说明稳定段更容易分类；若暴露级准确率仍为 100%，应同时强调系统已经能够正确识别整次暴露。
- 若去除 CH2 或改用电导提高性能，结论应先限定为当前 P2→P3、当前采集批次，等待独立数据确认。
