# B2/B5 跨方向分类结果（2026-07-15）

## 1. 实验合同

- 所有结果均为 `seed=42` 的真实设备实验，不使用本地模拟训练。
- F1 使用 Pi=C1、目标域 C5；R1 使用 Pi=C5、目标域 C1；R2 使用 Pi=C4 与 PC=C5、目标域 C1。
- B2 与 B5 在每个方向内使用相同的数据、硬件、25 轮训练预算和目标 calibration/test 切分。
- F1 test 为 1360 个窗口；R1/R2 test 均为同一协议下的 2680 个 C1 窗口。

## 4. 当前可以支持的结论

1. B2 是很强的轻量配置。在 C1 -> C5 中，它以更少的适配项取得六运行中的高水平结果，并且数值优于 B5。
2. B5 不能被简单判定为“模块无效”。在较困难的 C5 -> C1 反向迁移中，B5 显著降低错误；在 C4+C5 -> C1 中也取得更好的点估计、NLL、ECE 和最差类别召回。
3. B5 的额外 CORAL、同类同阶段对齐和 Wasserstein 适配没有表现出跨方向一致的叠加增益。R2 按 Accuracy、Macro-F1、最差类别召回同时不低于 0.5 pp 的预声明规则判为 `B5_favored`，但这不等同于显著性检验通过。更严谨的总表述是：完整适配栈的收益具有方向和源域异质性依赖。
4. 当前论文可以把 B2 定位为高性价比核心方法，把 B5 定位为面向困难反向迁移和多源异质性的鲁棒增强配置。最终是否保留完整 B5，需要结合种子 43-46、端侧开销和通信成本共同决定。
5. 三个方向目前都只有一个种子。除 C5 -> C1 的同窗口 seed-42 检验外，不应把单次结果写成跨随机种子的普遍优越性。
