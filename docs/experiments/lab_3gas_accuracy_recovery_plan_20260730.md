# 实验室三气体分类准确率恢复计划（P2 → P3，全浓度）

## 1. 目标与边界

- 目标：解释并改善实验室自测数据在 P2 → P3 迁移下的三分类窗口级准确率下降。
- 当前正式基线：窗口准确率 91.90%，Macro-F1 91.91%，暴露级准确率 100%。
- 本计划不做五折、不做浓度回归，只使用 P2 训练/源域、P3 校准/目标域和 P3 测试。
- 固定训练预算：联邦训练 25 轮，本地训练 3 轮，batch size 32；除明确消融项外，其余配置不变。
- 当前 P3 test 已被查看，因此本轮后续结果属于 post-hoc 探索性证据；最终确认需使用新日期或独立重复实验。

## 2. 当前证据与主要假设

### H1：早期进气瞬态降低窗口级准确率

当前 P3 校准只覆盖每次暴露的基础窗口索引 3、11、19，而测试还包含索引 0、1，对应约 0–150 s 的早期进气段。诊断分类器中，索引 0、1 明显更难，其余测试时间索引可完全分开。正式结果的暴露级准确率已达到 100%，也说明主要问题更可能是暴露内部的局部时间窗，而不是整次气体身份识别失败。

### H2：实验室预处理使用了相对电阻，而公共数据合同使用相对电导

当前实验室构建脚本使用 `(R-R0)/R0`；公共数据的特征合同是先做 `G=1/R`，再计算 `(G-G0)/G0`。相对电阻在强响应时会压缩到 -1 附近，而且 P2 与 P3 的饱和比例不同。该变换差异可能放大板间域偏移。

### H3：P2 与 P3 的域偏移集中在甲烷—乙酸及 CH2

诊断描述符显示：

- P2→P3 的甲烷类中心漂移为 0.489，高于 P3 内甲烷—乙酸类间距离 0.221。
- 正式混淆矩阵中最大错误为甲烷→乙酸，共 18 个窗口。
- CH2 的板间均值漂移较大、类间判别力弱；诊断性去除 CH2 后准确率由 96.90% 升至 98.81%。

以上数值只用于提出消融假设，不能直接替代正式 GAPS 模型结果。

### H4：实验室运行的域适配设置与公共数据 98–99% 的设置并不一致

实验室基线使用旧版 strong 配置：CORAL、对抗损失、legacy quartic MMD、legacy intra-domain stage；公共 B2 使用 corrected proto-replay 配置：关闭 CORAL/对抗，使用 MMD² 与 cross-domain same-class-phase。两者不能视为“训练代码流程完全一样”。

### H5：公共数据对目标校准分布更友好

公共数据的 calibration/test 是同一批原始文件中的窗口级随机分层，校准到测试的标准化最近邻距离中位数约为实验室 time-purged 划分的 19%。此外，公共源训练窗口和目标校准窗口均显著更多。因此 98–99% 不能作为当前实验室协议下的直接等价基准。

## 3. 固定数据协议

- 源域：P2，三气体，v1/v2 各去掉第一个不稳定浓度，使用后五个浓度。
- 目标域：P3，完全相同的三气体与浓度范围。
- 全浓度原则：P3 calibration 与 test 均覆盖全部保留浓度。
- 不做五折。
- 不通过 P3 test 选择超参数或通道组合。
- 配置选择时，将当前 P3 calibration 的每次暴露三个窗口固定拆成：
  - DA-fit：基础索引 3、11，共 60 个窗口；
  - config-validation：基础索引 19，共 30 个窗口。
- 最终候选确定前保持 P3 test 封存。鉴于当前 test 已经查看，最终 test 结果仅标记为探索性；独立新采集数据用于确认。

## 4. 实验顺序

### REC-A0：可复现基线

- 相对电阻、6 通道、完整 0–1200 s 时间范围。
- 保留旧版 strong DA 设置。
- 固定以第 25 轮评估，同时记录原有第 2 轮结果，区分模型差异与 checkpoint 选择差异。

### REC-A1：仅更换 corrected B2 域适配

- 关闭 CORAL 和 adversarial。
- MMD 使用 `mmd2`。
- stage 使用 `cross_domain_same_class_phase`。
- 其余数据、通道和预处理与 REC-A0 相同。

### REC-A2：仅加入目标校准监督

- 以 REC-A1 为基准。
- 固定 `lambda_target_ce=1.0`，不做网格搜索。
- 目标标签的使用必须在结果中明确披露。

### REC-A3：仅改为精确相对电导

- 以 REC-A1 为基准。
- 必须从原始电阻先计算 `G=1/R`，再做 `(G-G0)/G0`，之后再平滑和降采样。
- 归一化统计量只用 P2 train。
- 不使用由已平滑相对电阻近似反推的电导作为正式输入。

### REC-A4：仅去除早期瞬态

- 以 REC-A1 为基准。
- 固定分类起点为 150 s，排除基础索引 0、1。
- 同时报告完整测试与共同稳定时间范围上的结果。
- 覆盖率为 360/420 = 85.71%。被排除的两个困难窗口分别为
  0–100 s 和 50–150 s；由于 150–250 s 用作校准且相邻窗口被 purge，
  独立 test 中保留的第一个窗口从 250 s 开始。必须同时报告时间范围和
  覆盖率，不能只报告更高准确率。

### REC-A5：仅去除 CH2

- 以 REC-A1 为基准。
- 使用 CH1、CH4、CH6、CH8、CH9，模型输入维度改为 5。
- 不继续根据 P3 test 枚举其他通道组合。

### REC-A6：组合候选

- 只组合在 config-validation 上达到预设门槛的因素。
- 组合顺序优先为：精确相对电导 → corrected B2 → 早期瞬态策略 → CH2 消融 → 目标校准监督。
- 组合候选仅打开一次 P3 test；结果标记为探索性。

## 5. 指标与晋级规则

主要指标：

- 窗口级 Macro-F1；
- 窗口级 accuracy；
- 每类 recall 和 3×3 confusion matrix；
- 暴露级 accuracy；
- 若裁剪时间范围，额外报告覆盖率与最早可判定时间。

单因素晋级到组合候选需同时满足：

1. config-validation Macro-F1 相对 REC-A1 提升至少 2 个百分点；
2. 任一类别 recall 不低于 0.90；
3. 暴露级准确率不下降；
4. 数据合同、归一化来源和非有限值检查通过。

期望目标是窗口级 accuracy 和 Macro-F1 接近或达到 0.98，但该数值不是成功判定的唯一条件，也不能通过反复查看 P3 test 来优化。

## 6. 停止条件与风险控制

- 不围绕 P3 test 做学习率、通道、时间阈值或损失权重网格搜索。
- 精确相对电导若出现非有限值，先检查原始电阻零值、负值和基线区间，不进入训练。
- 早期裁剪若提升 accuracy 但显著降低覆盖率，只能表述为“稳定段准确率提升”。
- 单次 seed 只用于筛选；最终候选建议使用 seed 42、43、44 做内部稳定性检查。
- 论文级结论必须在新日期或独立重复采集的 P3 数据上确认。
