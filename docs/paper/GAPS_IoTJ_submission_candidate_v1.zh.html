GAPS：真实设备联邦分类、充分统计量回归参考与轻量目标个性化的跨设备气体感知系统

GAPS: Cross-Device Gas Sensing with Real-Device Federated Classification, a Sufficient-Statistics Regression Reference, and Lightweight Target Personalization

摘要

跨设备气体感知需要同时处理类别识别、浓度估计和可靠输出中的设备偏移。本文围绕三个问题构建 GAPS：真实设备联邦分类能否通过目标校准辅助的服务器端适配获得稳定路由；源设备能否仅交换充分统计量重构 Federated H1 回归参考，并以 105D 目标 Ridge 完成轻量个性化；上述链路在边缘效率、选择性输出和校准预算方面具有何种收益与边界。五个训练种子上，B5 accuracy 为 0.989118 ± 0.005983。在 seeds 42–46 产生的五条冻结 B5 routes 上，Federated-H1 个性化的 S_CC RMSE 为 11.6339 ± 0.3142 ppm；相对 all-prior 的退化为 0.981637%，满足预注册 1% 非劣标准，但 all-prior 的绝对均值略低。正式 seed-42 target 结果为 11.3416 ppm。v5 回归核心的回归参数由 28,737 减至 844；Raspberry Pi 5 p50 延迟由 4.571 ms 降至 3.725 ms，但 PC p95 并未同步改善。v5 QC2 以较低覆盖率换取较低 accepted error，且未通过 HC90 CO promotion guard，因此 v4 保留为正式选择性输出基线。统一 group-aware 描述性分析还显示，C5 calibration 从 320 减至 160 个窗口时，mean S_CC RMSE 从 10.8724 增至 23.9156 ppm。结果表明，GAPS 在当前 calibrated-target held-out-window evaluation 下兼顾了路由稳定性、回归依赖简化与边缘可执行性，但其证据不等同于对全新原始文件或会话的泛化。

关键词：真实设备联邦分类；服务器端域适应；充分统计量 Federated Ridge；目标个性化；选择性输出；校准预算敏感性

I. 引言

金属氧化物半导体阵列易受制造差异、漂移和工作环境影响，使源设备模型难以直接迁移到新设备 [1], [2], [19]。对于气体感知，分类错误还会改变浓度专家路由，因此分类、回归和选择性输出需要在同一系统链路中评价。已有联邦学习与边云协同研究提供了去中心化优化基础 [3], [4], [16]–[18]，但目标设备仍需要透明的 calibration 资源与可审计的可靠性边界。

GAPS 将系统划分为四个证据一致的阶段：真实设备联邦分类与服务器端域适应；源端充分统计量聚合得到共享回归参考；目标端轻量 Ridge 个性化；以及 accept/review/reject 三态输出。本研究不声称完整端到端回归在网络中联邦训练，也不为充分统计量交换提供形式化隐私保证。

RQ1. 在 C1/C2→C5 的真实三机拓扑中，联邦分类与 calibration-assisted server adaptation 能否形成稳定的气体类别路由？

RQ2. 仅聚合源端充分统计量得到的 Federated H1，能否与 104D rich features 组合为 105D 轻量目标个性化，并在预注册简化非劣门槛下替代三 reference all-prior 依赖？

RQ3. 最终链路在边缘效率、选择性输出的质量—覆盖率权衡以及 calibration boundary 上表现如何？

围绕上述研究问题，本文贡献为：

  1. 实现真实设备联邦分类与目标校准辅助的服务器端适配，并用 seeds 42–46 评价冻结 B5 在当前 C1/C2→C5 协议下的稳定性。
  2. 以源端局部特征矩、正规方程和校准统计构建 sufficient-statistics Federated H1；原始源样本行保持本地，并将其预测与 104D rich features 组合为 105D 轻量目标 Ridge 个性化。
  3. 对效果、边缘效率、应用层通信、选择性输出和 calibration-budget sensitivity 进行系统评估，同时明确 window-level 评价、隐私机制与运行时角色的证据边界。

II. 相关工作

传统传感器漂移与校准迁移方法通常依赖匹配样本、特征映射或重新标定 [1], [2], [15], [19]。FedAvg、FedProx 与 federated sensing 研究分别讨论模型聚合、系统异质性和边云协同 [3], [4], [16]–[18]。MMD、CORAL、域对抗与原型网络分别为分布匹配和语义约束提供基础 [5]–[8]；experience replay [9] 在本项目中只对应历史机制语义，不用于支持域适应或原型学习主张。选择性预测强调在误差与覆盖率之间建立显式工作点 [10]–[12]。GAPS 的区别在于：把真实设备分类、充分统计量回归 reference、目标个性化及三态输出绑定为一条可审计系统链路，而不把 selective aggregation 本身作为主要创新。

Data protocol. 本文将目标设备协议统一称为 calibrated-target held-out-window evaluation。先从原始 measurement files 构造 100×8 windows，再按 gas class 与 concentration 分层划分 C5 calibration/test，分别包含 320/1360 个 windows。同一个具体 window/sample row 只属于一个 subset，不跨 calibration 与 test 重复；但同一原始文件生成的不同 windows 可以分别出现在两个 subsets。因此，该协议不强制原始文件互斥，也不表示对全新 measurement runs 的泛化。历史 calibration 内部 240/80 selection 仍为 window-level；filename overlap 描述的是 grouping dependence，不等同于使用 test labels 训练。

IV. 方法

A. 真实设备联邦分类

B5 使用卷积残差块与多头注意力组成分类骨干；这些通用组件分别参考 residual learning 与 attention architecture [13], [14]，并非本文的独立算法贡献。C1/C2 使用 Client Adam（learning rate 5×10−4）、batch size 32、每轮五个 local epochs 训练。服务器执行 25 个 communication rounds，并在每轮执行 100 个 calibration-assisted server-side adaptation steps。五种子仅改变随机种子；拓扑、数据、优化器和 B5 开关保持冻结。由于适配使用 C5 calibration labels，本文称其为 calibration-assisted adaptation，而不是 zero-shot transfer 或 unsupervised domain adaptation。

B. Sufficient-statistics Federated Ridge

四类气体独立拟合。客户端首先计算局部特征计数、均值及二阶矩，服务器聚合后重构 global scaler。对每个候选 Ridge 系数 α，客户端在标准化特征上构造带截距的正规方程 XTX 与 XTy；服务器求解候选模型，再由客户端返回 clipped validation SSE 与计数用于 calibration-only α 选择。选定 α 后聚合完整 source fit statistics 并重构最终 H1。交换内容不包含原始 source rows、X/y 表或逐样本预测；但统计量没有安全聚合或差分隐私保护。

C. 目标个性化

C5 为每个窗口提取 104D rich features，并附加 1D Federated H1 prediction，形成 105D 输入。根据冻结 B5 predicted class 路由到四个独立 target Ridge。α 仅由 C5 calibration 内部 fit/validation 或 group-aware folds 选择，随后在当前完整 calibration subset 上 refit。Test labels 不用于 model fitting、hyperparameter selection、alpha selection、QC threshold selection 或 checkpoint selection；evidence freeze 之后也不再进行 method selection 或 reselection。

D. Runtime 与 QC 角色

Runtime v4 是包含多 reference/multi-expert 风险语义的正式 selective-output baseline；其 accepted RMSE 与覆盖率只描述该正式 QC 运行对象。Portable Runtime v5 core 实现 B5→Federated H1→105D target Ridge 的简化回归核心，提供工程可移植性证据，不携带 v4 正式 QC 的性能身份。v5 QC2 使用 confidence 与 prototype/support distance 构建独立候选风险。HC95/HC90 均产生 accept、review、reject；只有 accept 行输出 auto_output_ppm。v4 正式 QC、v5 regression core 和 v5 QC2 candidate 的功能身份不可混写。

V. 实验协议

Evaluation protocol. 正式目标设备评价采用 calibrated-target held-out-window evaluation：window construction precedes splitting；C5 windows 按 gas class 与 concentration 分层为 320 calibration 和 1360 test。同一具体 window/sample row 不跨 subset，但同一 original file 的不同 windows 可以同时出现在 calibration 与 test。Filename overlap 与 test-label leakage 是不同问题：前者限制 original-file/session-level 外推，后者涉及是否使用 test labels 进行训练或选择。本文 test labels 不参与 fitting、hyperparameter/alpha/QC-threshold/checkpoint selection；evidence freeze 后不再选择方法。分类标准差来自 seeds 42–46；回归标准差来自五个冻结 B5 routes。S_CC 只统计分类路由正确行，S_ALL 统计全部 test 行。Low-calibration 与 harmonization 仅为 frozen-method post-freeze 描述性分析，不用于方法重选。

Seed scope. 五种子分类统计改变完整 B5 训练随机种子。五种子回归比较则复用冻结的 source H1/H2/H3 heads 与相同 target regression protocol，只改变 seeds 42–46 产生的 B5 predicted routes；因此该统计不表示所有回归 head 均被独立重训五次。

C. RQ3：选择性输出、效率与校准边界

v5 QC2 在 HC95/HC90 上分别取得 13.9178/12.7723 ppm accepted RMSE，但 accepted yield 仅为 93.75%/86.99%。相对 v4，yield 分别下降 3.53/3.82 percentage points。HC90 CO yield 从 84.71% 降至 64.12%，CO accepted RMSE 从 19.7243 增至 20.8318 ppm，因此 v5 QC2 未晋级，v4 保持正式 baseline。

统一 group-aware protocol 下，320→160 windows 使 mean S_CC RMSE 从 10.8724 增至 23.9156 ppm，超过两倍；CO-high 与 Methane 尤其敏感。10.8724 ppm 是 group-aware fold-selection 均值，不能替代正式 historical protocol 下的 frozen seed-42 RG1 结果 11.3416 ppm。

Historical holdout 与 group-aware 两条轨迹均随预算下降而退化，但幅度随 protocol 和 budget 改变，最终描述为 SENSITIVITY_PARTLY_PROTOCOL_DEPENDENT。Historical 240/80 保留 window-level membership；harmonization 不选择更优 protocol，也不覆盖正式 11.3416 ppm 主结果。

VII. 讨论与局限

Calibration sensitivity. 在统一 group-aware protocol 下，将 target calibration 从 320 减至 160 windows 使 mean S_CC RMSE 超过两倍。两种 protocol 的退化方向一致，但退化幅度部分依赖内部 selection protocol 与 budget。

Evaluation boundary. 目标设备评价采用类别—浓度分层的 window-level split。同一 measurement file 产生的不同窗口可能分别出现在 calibration 与 test；因此，本文报告的是 calibration 后的 held-out-window performance，而不是 original-file-independent 或 unseen-session generalization。该协议也不支持 zero-shot target generalization 表述。

该边界反映原始文件层面的相关性，而不是 test-label leakage：同一个具体 window/sample row 不跨 subset，且 test labels 未进入 fitting 或冻结选择流程。历史 calibration 内部 240/80 selection 以及 post-freeze sensitivity 分析继续按各自已登记的 window-level 边界解释。

Gas and QC limitations. CO-high 与 Methane 对 calibration coverage 尤其敏感。v5 QC2 能富集高误差样本，但 coverage 与 HC90 CO guards 未通过，因此没有取代 v4。

Privacy boundary. Federated H1 构建中 raw source samples remain local；交换的 sufficient statistics 没有安全聚合或差分隐私保护，本文不主张形式化隐私保证。

Seed and runtime boundary. 回归五种子结果改变的是冻结 B5 classifiers 产生的 route，不是对全部 source/target regression heads 的五次独立训练。v4 formal QC 与 portable v5 regression core 属于不同运行对象：前者承载正式选择性输出证据，后者只承载简化回归核心的工程可移植性证据，二者的 accepted RMSE 与参数量不得拼接为同一个 runtime claim。

Future work. 后续工作仅包括 unseen-session 或 original-file-independent evaluation、更多 physical target devices，以及针对 sufficient statistics 的更强隐私保护。FedProx/FedAdam/SCAFFOLD 排名、多目标 reruns、新 QC 和新 regression heads 不属于当前投稿范围或待完成实验。

VIII. 结论

GAPS 在真实设备联邦分类、充分统计量 source regression reference 与轻量 target personalization 之间建立了可执行闭环。五种子结果支持 B5 在当前协议下的分类稳定性；Federated H1 在预注册 1% margin 下相对 all-prior 非劣，并将 source regression references 从三个减为一个，实现依赖的大幅简化；回归参数由 28,737 减至 844。v5 QC2 的 promotion guards 未满足，因此 v4 保留为正式 selective-output baseline。结合 window-level 评价、平台相关延迟、隐私机制缺口和 calibration sensitivity，这些结果界定了当前系统的效果、效率与可靠部署边界。
