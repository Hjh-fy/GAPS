# 实验室三气体 A1 全响应跨板实验设计

日期：2026-07-31

状态：待实施

范围：seed 42、三组方向、正式三机拓扑、顺序运行

## 1. 研究问题

在 A1 全响应协议中，将每次目标气体暴露的 0–150 s 早期窗口加入源域训练和目标测试后，三气体跨板分类在完整响应范围、早期动态段和稳定段分别达到什么性能？源板方向和双源组合是否影响结果？

本轮只进行三分类，不进行浓度回归、五折或多随机种子实验。

## 2. 三组正式实验

| 实验 ID | 方向 | 源域执行节点 | 目标校准与测试 | 归一化拟合范围 |
|---|---|---|---|---|
| A1-FULL-E1-P2P3-S42 | P2→P3 | 云服务器 B，逻辑客户端 P2/C2 | 云服务器 A 上的 P3 数据 | 仅 P2 train |
| A1-FULL-E2-P12P3-S42 | P1+P2→P3 | 树莓派 P1/C1 + 云服务器 B P2/C2 | 云服务器 A 上的 P3 数据 | P1+P2 train 联合拟合 |
| A1-FULL-E3-P3P1-S42 | P3→P1 | 树莓派，逻辑客户端 P3/C3 | 云服务器 A 上的 P1 数据 | 仅 P3 train |

P3→P1 中，树莓派仍是物理边缘客户端，但加载 P3 数据并以逻辑 `client_id=3` 运行。云服务器 B 不参加该方向。云服务器 A 在全部方向中负责 Flower Server、目标校准数据和 Server DA。

三组严格顺序运行；任一组只有在数据合同、代码身份、三端预检和 postflight audit 通过后才登记为有效结果。

## 3. 数据协议

- 每个平台保留乙醛、甲烷、乙酸三种气体，v1/v2 各去掉第一个不稳定浓度，合计每板 30 次暴露。
- 输入使用相对电阻及 CH1、CH2、CH4、CH6、CH8、CH9，单窗口形状为 `100×6`。
- 每次暴露共有 23 个基础窗口。
- calibration 索引固定为 `[3, 11, 19]`，每板共 90 个窗口。
- purge 索引固定为 `[2, 4, 10, 12, 18, 20]`，禁止 calibration 与 train/test 原始时间重叠。
- A1 全响应 train/test 索引固定为 `[0, 1, 5, 6, 7, 8, 9, 13, 14, 15, 16, 17, 21, 22]`，每板共 420 个窗口。
- `early60` 为索引 `[0, 1]`，共 60 个窗口；`stable360` 为其余 12 个 A1 索引，共 360 个窗口；`full420` 为主测试范围。
- 目标 calibration 与目标 test 均覆盖全部保留浓度，但样本索引与原始时间范围隔离。本协议不用于声称未见浓度泛化。

## 4. 固定训练配置

| 参数 | 固定值 |
|---|---|
| seed | 42 |
| 联邦轮数 | 25 |
| 本地训练轮数 | 1 |
| Server DA 步数 | 100 |
| batch size | 32 |
| 模型配置 | `proto_replay` |
| 域适配 | `corrected_b2` |
| target CE weight | 0 |
| 输入通道数 | 6 |
| 检查点策略 | 固定 round 25 |

除源客户端、目标客户端、全响应数据范围和明确指定的本地训练 1 轮外，其余配置保持现有 A1/corrected-B2 合同不变。目标 test 不参与训练、Server DA、超参数选择或轮次选择。

## 5. 假设与预期证据

### H-A1-FULL-01：早期窗口可学习性

假设：将 0–150 s 加入源域训练后，冻结 round-25 模型在对应目标板 `early60` 上能够学习到非随机的三气体区分信息。

证据：报告 early60 的窗口级 Accuracy、Macro-F1、每类召回率、混淆矩阵和暴露级 Accuracy。不得预设一定高于 A4。

### H-A1-FULL-02：完整范围与稳定段权衡

假设：全响应训练可能提高 early60 或 full420，但也可能牺牲 stable360。

证据：同一检查点同时报告 full420、early60、stable360；使用正确窗口数和百分点差描述与已有同方向 A4 结果的差异。

### H-A1-FULL-03：源板方向与双源组合

假设：P2、P1+P2 和 P3 源域具有不同的跨板动态迁移能力。

证据：P2→P3 与 P1+P2→P3 可在相同 P3 目标上作 seed-42 描述性比较；P3→P1 因目标板不同，只作反向迁移结果，不加入 P3 排名。

## 6. 比较边界

本轮相对既有 A4 同时改变了两个因素：训练时间范围由稳定 360 窗口改为完整 420 窗口，本地训练轮数由 3 改为 1。因此，新 A1 与旧 A4 的比较不是严格单因素消融，差异不能全部归因于加入 0–150 s。

P1+P2→P3 使用两个源客户端和更多源样本，且没有匹配单源样本预算，不能将差异单独解释为源域多样性的因果效果。单 seed 结果只作为描述性证据，不计算跨种子稳定性或统计显著性。

## 7. 实施范围

1. 扩展数据构建器以支持 A1 全响应三方向及 P3→P1。
2. 扩展控制器方向映射，使树莓派能够按运行配置加载 P1 或 P3 数据并使用对应逻辑 client ID。
3. 为三端生成新的内容寻址源码归档和独立数据目录，不覆盖 A4 数据或运行目录。
4. 先运行本地合同测试，再进行三端只读预检和最小 smoke check。
5. 按 P2→P3、P1+P2→P3、P3→P1 顺序正式运行。
6. 每组保存 25 轮 base/adapted 检查点、正式评估、postflight audit 和轻量汇总。

## 8. 停止规则

- 数据集不是 420 train / 90 calibration / 420 test，停止。
- 归一化客户端与源域不一致，停止。
- 树莓派逻辑 client ID 或加载的平台数据不符合方向，停止。
- 目标 test 在 round 25 锁定前被用于选择，停止。
- 任一远端源码 SHA、数据 manifest 或输入形状不一致，停止。
- 运行卡住时先保留日志和现场证据，不直接覆盖原运行目录重启。
