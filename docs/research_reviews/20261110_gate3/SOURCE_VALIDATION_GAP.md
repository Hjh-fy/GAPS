# 源节点独立保护证据缺口

原八条约束中的源四类继续用 C1 Day4 与 C2 Day1/7 合法训练池计算。Gate 3 只评分 C5 Day18 开发暴露，因而没有独立源 CE、保持率或保护能力结论。

Phase 0.5 的角色清单将 C1 Day10、Day15 和 C2 Day11 标为 unused，每个设备日各 40 次暴露，可作为**待审查**的源开发候选。它们晚于 Day7 合法源起点，早于 C5 Day18 接入。后续必须逐个核验原始文件 SHA、是否进入 S* 或 B4 的完整祖先、历史结果是否被用于决策，以及时间与访问规则，然后独立登记。已有旧协议使用源 R1–R3，不能把这些暴露统称为历史未使用数据。

Phase 3.5 已公开观察 C1 Day21 与 C2 Day16 源保持结果，继续作为历史证据，不用于选择新策略。任何独立源保护主张都应先固定物理暴露等权、最坏类风险和回退合同。
