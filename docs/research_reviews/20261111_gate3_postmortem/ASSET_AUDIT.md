# 独立物理暴露资产与历史使用

本轮仅用角色表、原始采集审计、训练导出身份、访问账本与 v5 归档元数据核对。640 个暴露的 raw SHA、canonical numeric SHA 和相对采集日，在两份封存身份表中一致。本轮未重新读取原始信号，因此该结论是封存元数据一致性；没有新增现场 raw SHA 验收。日程为相对日，绝对日期及不同文件真实墙钟仍未知。

当前 S* 的 25 轮收据均只包含 C1/C2 的 840/1,680 窗，最终 state 与 B4 首轮接收值一致。Phase 3.1 的源与标定导出账本含 136 次暴露，其中源 120 次、C5 Day18 A4 16 次。下表候选均没有进入当前这条模型祖先的训练身份。

C1 Day21、C2 Day16、C3 Day17 和 C5 Day22 已有历史测试或缓存使用，不能被重新命名为首次盲测。其他设备的不同物理暴露也不能直接替代 C5 的未来同设备确认。旧资产的选参记录并非全部闭合，足以支持受限回顾性开发的数据，尚不能自动升级成独立确认队列。
