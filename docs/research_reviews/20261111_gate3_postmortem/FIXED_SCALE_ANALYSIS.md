# 固定缩放 CE 曲线与已有非线性证据

| 轮次 / 气体 | α=0 | α=0.25 | α=0.5 | α=1 |
| --- | ---: | ---: | ---: | ---: |
| 5 / Ethanol | 0 | +0.443658 | +0.701748 | +0.541843 |
| 5 / Ethylene | 0 | +4.80548e-7 | +1.98682e-6 | +3.32011e-5 |
| 5 / Methane | 0 | +0.0235891 | +0.0472186 | +0.0894806 |
| 1 / Methane | 0 | +0.0747005 | +0.152188 | +0.362986 |

每格是同气体六次开发暴露的 CE 变化均值。Ethylene 在 α=0.25 的类均值处于原零带，α=0.5 的变化超过该零带。Ethanol 与 Methane 在最小已测位移 0.25 已出现与标定一阶风险相反的方向，因此不能仅凭“完整位移太大”解释观察；也不能据此断言起点梯度已经反向，因为 0.25 仍是有限位移。

Ethanol 的三段割线斜率为 +1.77463、+1.03236、−0.31981，类 CE 对尺度的变化非单调。Ethylene 的割线斜率随尺度增加，完整步增量明显大于小步增量线性延伸。Methane 三段斜率约 +0.09436、+0.09452、+0.08452，已测范围近似正向线性，但这不能确定 α=0 的导数。四个焦点曲线均偏离连接 0 与 1 的直线，偏离量超过原报告零带。这里只确认已测点不构成同一条直线，未估计 Hessian 或起点导数。

已有标定侧有限步评分还能检验一阶外推本身。第 5 轮 Ethanol 的标定 g·Δ 为 −5.19663，完整步标定 CE 只下降 −0.82749，两者差 +4.36915，说明标定一阶量也不宜直接当完整步 CE 幅值。另一方面，同一个完整位移在开发侧平均上升 +0.54184，和标定有限步之间还差 +1.36933。两种差异可同时存在，无法用前一项解释后一项的来源。

## 相同时间锚窗的封存评分补充

标定每暴露仅使用 [60,70) 与 [150,160) 两窗，开发主损失使用 21 个滑窗。为检查这一时间支持差异，本轮事后从已封存 CE 提取每次开发暴露的窗口 0、18，仍先按暴露内两窗均值、再按六暴露均值汇总，未增加任何模型计算。

完整反馈下，第 5 轮 Ethanol 的开发双锚窗均值变化为 +0.15947，五次暴露下降、25 ppm 暴露上升约 +0.97297，和 21 窗口径的五升一降明显不同。Methane 双锚窗均值为 +0.04758，Ethylene 为 +1.55256e-6。相同时间锚窗并未消除类别均值方向反转，但会改变其幅度及暴露分布。这支持审查时间支持的代表性，不能证明它是失效原因。主评价继续沿用 21 窗，双锚窗仅为回顾性描述。

A/B 及两个同范数缩放的完整结果均保留。它们在不同暴露上的损失变化往往同序，幅度与局部符号仍有差异，没有据本轮数据重新选择投影或反馈系数。
