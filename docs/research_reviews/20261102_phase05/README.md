## 身份、日期和时间的证据边界

一个暴露身份为名义600秒的完整原始记录文件，主键(client, filename)，另保存字节SHA与完整float64数值SHA。每个重复包含4气体×10档=40个不同条件。文件编码设备、气体、浓度档位及重复号，不能把滑窗数量当独立标定次数。

日程已与[UCI Twin gas sensor arrays官方说明](https://archive.ics.uci.edu/dataset/361/twin+gas+sensor+arrays)核对；重复号到相对日沿用已归档strict_data解析并逐文件与旧索引交叉检查。原始文件只有重置后的elapsed seconds和8路电阻，没有绝对日历日期及每日暴露开始时刻；它们均为UNKNOWN，不使用文件mtime或2016捐赠日期冒充采集日期。同日呈现顺序发布为随机，不能按文件名排序虚构真实事件顺序。

文件/数值SHA互斥证明没有复用同一整段数字记录；不同暴露间的真实墙钟重叠和近重复片段未经绝对时间证明，仍UNKNOWN。相对时间均从0附近开始，不是不同文件同步发生的证据，也不能将其相减报“跨文件时间重叠0秒”。同日环境/设备状态仍可能相关，独立暴露单位不等于独立采集日或IID证据。

实际各文件有19,289–60,001行，elapsed均从0开始、结束于599.89–600.00秒。466个文件含重复时间戳，共51,618个重复行；未发现时间逆序或非正电阻值。重复时间戳按原process_arrays合并平均，不能当成重复暴露或新增独立样本。该原始采样质量事实及数量保存在TIME_AXIS_AUDIT.json。

## 2/4次预算与浓度覆盖

标定2次固定F010/F100；4次固定F010/F040/F070/F100，2次严格嵌套于4次。每档各一个完整记录，而非同浓度4个重复或4个日期。两预算的development完全相同；2次预算中的F040/F070保留为reserved，不移入development。

|气体|2次标定ppm|4次标定ppm|
|---|---|---|
|Ethanol、Ethylene|12.5,125|12.5,50,87.5,125|
|CO、Methane|25,250|25,100,175,250|

每目标4气体共8/16次标定。沿用原实现固定[60,70)、[150,160)各一窗，因此16/32个训练窗；窗口不是额外独立标签。测试每气体10档，共40暴露、840有效窗；2/4次分别只有2/4个已见浓度档，剩余8/6档是量程内未见档位，不是量程外外推。原始标签量程及单位保持不变。

development标签若参与选参、回退、方法选择或阈值，则目标监督总量为：C3的48/56次，C4/C5的32/40次，而不是8/16次。下一轮主矩阵采用严格总预算：仅标定标签用于目标拟合，超参数在合法源侧确定，target development不参与选择。若需要target development监督，必须另列DEV-supervised协议、对全部方法给予相同标签，并报告完整成本。
