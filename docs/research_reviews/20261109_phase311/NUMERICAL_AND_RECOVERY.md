# 实机数值与恢复证据

Pi 每次向分类器提交 contiguous float32 单窗，输入形状为 1×50×8。现有 71D 特征和 scikit-learn SVR 数值路径沿用冻结的 float64 表示。FP32 指分类端计算精度。六组共用同一套四个 C5 A4 F-SVR71 头。回归头仅按分类器预测 ID 选取，真实类别未进入设备包或运行接口。

门禁逐分量比较 |Pi − PC| ≤ atol + rtol × |PC|。logits 沿用 PC 单窗的 1e-4 / 1e-5，71D 用 1e-8 / 1e-7，ppm 用 1e-4 / 1e-6。后两项在实机输出前确定，依据封存 PC 标定与合成参考的重复恢复一致性、冻结的浮点实现及物理 ppm 输出所需精度，属于工程验收容差。设备类别、实际调用头、版本、支持范围和状态必须精确相同。浮点运算的不同计算路径可能造成平台差异，当前证据未定位到具体算子。[PyTorch 数值精度说明](https://docs.pytorch.org/docs/stable/notes/numerical_accuracy.html)

## Gate A

216/216 条联合输出通过。logits 最大绝对差 4.0114e-5，71D 最大差 0，路由后浓度最大差 2.5580e-13 ppm。四头各 36 次直接检查共 144 次通过。同进程重复、完整重载及独立进程重启的完整预测文件 SHA 相同。缺失分类器、模型哈希不符和无法反序列化均拒绝候选并保留健康快照，保存恢复前后实际数值。冷启动失败返回 MODEL_NOT_READY。缺失 SVR 头、非法形状、非有限输入、非有限分类 logits 及非有限 raw 浓度均返回对应不可用状态，raw 非有限在裁剪前拦截。
