# PC 单窗异常恢复

第五次复验进程通过冻结 JointBridge 执行 15 个合成边界探针。错误形状和 dtype、NaN/Inf 信号、分类异常、非法类别或 logits、无效分类或回归版本、缺头、71D schema 不符及非有限浓度均返回 UNAVAILABLE。分类失败的探针没有调用回归头。raw 为 NaN 或 Inf 时，在 clip 前拒绝。逐项原因及调用次数见 [复验结果](attempt5/verify/RESULT.json)。

| 恢复场景 | 注入位置 | 观察结果 |
|---|---|---|
| scaler 指纹不符 | 候选头的独立副本 | 候选拒绝激活。旧快照保持服务，B0 合成窗口 logits 和路由输出一致 |
| 已有快照时重载失败 | 真实 B0 加载路径的缺失文件 | 捕获 FileNotFoundError，旧快照保持服务。健康检查与初始输出一致 |
| 冷启动加载失败 | 同一缺失文件路径 | 返回 MODEL_NOT_READY，未进行数值前向 |
| 随后完整重载 | 重新构建冻结六端点及四头 | 36 窗完整复验通过。旧快照替换前以及新快照前后的状态和 scaler 哈希均匹配原锁 |

两个真实打开失败均由复验进程持久化。预测路由仅使用 logits 的 argmax。额外四头数值检查独立登记为 all_heads 请求，其输出不参与路由。
