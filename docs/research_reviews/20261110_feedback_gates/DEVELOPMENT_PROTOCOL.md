# 后续开发数据协议

现有暴露独立的开发资产可用。C5 Day18 剩余固定 24 个物理暴露与 A4 16 个标定暴露、Day22 40 个历史测试暴露在文件 SHA 上互斥。C5 开发与标定同日，支持同日独立暴露开发，不能支持跨日期确认。C3 的 Day8 标定、Day14 开发 40 暴露、Day17 历史测试 40 暴露为三日期协议。C3 可作为另一设备的开发场景，不能替代 C5 独立采集日期。角色审计只读 Phase 0.5 清单和 Phase 3.1 身份元数据。

若另行授权后续开发，先冻结策略、终点、标签用途、评价阈值和窗口等权/暴露等权公式。校准标签只供更新和风险估计；开发暴露只做预定比较；Day22 保持封存。C1/C2 原训练池可以复用作诊断；如需源开发，必须另立按暴露分组、合乎时间顺序且未进入候选初始化或训练的角色。Phase 3.5 历史源保持测试不应用于策略选择。已有历史测试和模型报告均属已观察证据。

同一历史数据上的更多种子只表征训练随机性。若需要 C5 跨日期确认，仍缺新的独立合法证据。无需通过额外切分滑窗虚增暴露数量。
