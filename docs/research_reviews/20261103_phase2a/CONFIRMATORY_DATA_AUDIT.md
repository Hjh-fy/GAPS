# 独立确认性数据可用性审计

范围：Phase0.5 data1审计的640次原始暴露，以及当前原仓库canonical C1–C5的train/calibration/test暴露元数据，共12个存在的元数据文件。只检查身份和SHA，不打开目标信号/71D数值作新预测，也没有审遍所有其它worktree或外部数据源。

结果：640/640原始文件名均出现在这些历史元数据中；未在检查集合中找到的文件数为0。逐文件新A2/A4角色和旧split成员关系见evidence_v2/HISTORICAL_EXPOSURE_COVERAGE.csv，元数据路径、SHA、行数和独立文件数见HISTORICAL_METADATA_PROVENANCE.json。

历史元数据成员关系证明该暴露已进入既有数据流程，不能单凭它断言每一旧模型都训练/预测过每个窗口。但是它不支持“新协议unused/reserved角色就是从未观察的数据”的说法。尤其C3 R1的unused和A2保留档也不自动成为新盲测；近期Development未参与选参，同样不能证明全历史未使用。

当前已确认未触及、独立日期/设备的目标确认集数量=0；确切逐方法历史使用记录仍有unknown。本批目标test已知被历史研究查看，本轮全部推断仍回顾性。严格暴露互斥能回答新模型在固定留出暴露上的探索性表现，不能抹除先前方法构思/选择已看过同批数据的事实。

仅现有数据约束下的替代：预先固定合法源侧跨设备外层验证，明确仍是有限既有源任务的探索性诊断；如有未审查的独立历史日期/设备资产，先另做身份/使用谱系审计并封存，证据不足保持unknown。外部独立公开设备数据本轮未导入/审查，不假称已可用。若没有新的独立证据，后续不得宣称新算法普遍跨设备、前瞻性或长期闭环有效。
