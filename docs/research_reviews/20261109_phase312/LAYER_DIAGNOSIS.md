# 合法标定与合成输入的逐层数值证据

六个冻结分类端点分别运行同一批 32 个标定窗和 4 个合成窗。两端均按单窗 float32、CPU、eval、inference_mode 运行。保持 PC 原生 inter-op 6 和 Pi 原生 inter-op 1，intra-op 均为 1。两端 MKLDNN 和 MHA fastpath 保持启用。每平台各执行 216 次基线和 216 次只读 hook 推理，逐窗验证同平台加 hook 前后联合输出完全相同。没有进行后端开关或线程数单因素实验。PyTorch 对不同平台的浮点运算不保证逐位一致。[PyTorch 数值精度说明](https://docs.pytorch.org/docs/stable/notes/numerical_accuracy.html)

| 观测节点 | PC–Pi 最大绝对差 |
| --- | ---: |
| 模型输入、首块 TCN 输入与首块 depthwise 输出 | 0，逐字节相同 |
| 首块 TCN pointwise 输出 | 1.90735×10⁻⁶ |
| 首块残差相加及 ReLU 后输出 | 5.48363×10⁻⁶ |
| 第二块归一化输出 | 2.89723×10⁻⁴ |
| 第三块残差相加及 ReLU 后输出 / Attention 输入 | 2.81096×10⁻⁴ |
| Attention 输出 | 2.15650×10⁻⁴ |
| 分类投影输出 | 2.67029×10⁻⁵ |
| 最终 logits | 4.01139×10⁻⁵ |

216/216 组的首处可观察字节差异均为首块 pointwise 输出。各观测节点的 shape、dtype 与步幅在两端一致。最终 logits 有 215 组逐字节不同，216 组均通过原逐分量容差，argmax 变化为 0。PC 和 Pi 各自的最终 logits 与 Phase 3.11 封存的合法输入基线逐值一致。完整层清单包含张量摘要、SHA、分量数组和逐组差值。表中各层最大值可能来自不同窗口。

**证据等级。** 在这些合法输入上，首个可观测差异位置已定位到模块输出。具体底层内核、舍入顺序、线程或计算库的贡献未经独立控制，无法判定。数值路径差异已观察，历史 Day22 的 30 条超容差未在合法输入复现，完整根因仍未确认。

**后续合同。** 当前证据支持保留严格验收的原结论。如果实际业务只消费类别、路由和浓度，可另行提出合同，先定义分类决策及临界间隔要求、ppm 容差、异常与版本规则，再用独立输入验证。当前没有事先批准的业务精度要求，历史 Day22 超差不能用来反推新阈值。本阶段不发布替代合同。
