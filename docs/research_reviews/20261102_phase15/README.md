# FedOnGas Phase1.5：公平性修正与性能瓶颈审阅

2026-11-02。依据不可变v5、Phase0.5协议和Phase1固定提交772c0e9087435b9deb8ea4ac50b7c24814f6b345。研究属性：**回顾性探索，目标test此前已观察，不是新盲测**。全部新文件在独立worktree的本阶段目录；旧结果保留。

## 主要判断

1. Ridge原结论受到显著正则化迁移影响。只改alpha尺度的N控制，使六配置NRMSE均下降，六配置宏平均从27.995%到20.921%，下降7.074个百分点，约相当于原Ridge–SVR宏平均差距的76.7%。这是控制实验中的大部分差距缩减，不等于证明全部误差或全部跨域困难均由正则造成。
2. 主公平F流程下SVR六组均低于Ridge；差距缩到0.280–6.756个百分点，四组条件性bootstrap区间包含0，只能称方向性优势。F-Ridge均值21.005%，F-SVR 19.094%。F与N不是按target挑赢家的菜单，二者分别回答任务匹配和系数尺度问题。
3. KRR较F-SVR改善4/6，退步2/6，宏平均18.883% vs 19.094%，改善0.210个百分点。**停止扩大KRR网格及单纯换核模型方向**，保留已锁定KRR为低成本对照，不据这些test重新选参数。
4. 困难气体并非统一“少几个浓度点”。C4 Ethanol已见125ppm明显偏低且核相似度低；C5 CO已见250ppm仍失败且相似度较高；C3 Ethylene中档即使A4已标定仍大偏差。跨日输入关系、校准拟合偏差和时间变化共同出现，尚不能证明71D在所有方法下不可辨识，更不能归因为物理老化。
