## 对研究问题的直接回答

- 5%预算：同一分类器下，R84总体RMSE改善的分类器为 CLASS, FT, TO（3/3）。
- 5% / TARGET_RIDGE_83D：平均Accuracy排序 FT > CLASS > TO；平均RMSE由低到高 FT < CLASS < TO。
- 5% / R84_CONCAT：平均Accuracy排序 FT > CLASS > TO；平均RMSE由低到高 FT < CLASS < TO。
- 5% / FT:R84_CONCAT-TO:TARGET_RIDGE_83D：ΔRMSE=-2.54011 ppm；支持该固定协议下总体误差改善。
- 5% / CLASS:R84_CONCAT-TO:TARGET_RIDGE_83D：ΔRMSE=-2.38785 ppm；支持该固定协议下总体误差改善。
- 20%预算：同一分类器下，R84总体RMSE改善的分类器为 CLASS, FT, TO（3/3）。
- 20% / TARGET_RIDGE_83D：平均Accuracy排序 TO > CLASS > FT；平均RMSE由低到高 TO < CLASS < FT。
- 20% / R84_CONCAT：平均Accuracy排序 TO > CLASS > FT；平均RMSE由低到高 TO < CLASS < FT。
- 20% / FT:R84_CONCAT-TO:TARGET_RIDGE_83D：ΔRMSE=+3.05148 ppm；不支持相对TO+目标Ridge的总体误差优势。
- 20% / CLASS:R84_CONCAT-TO:TARGET_RIDGE_83D：ΔRMSE=+0.01136 ppm；不支持相对TO+目标Ridge的总体误差优势。

## 路由与回归映射的边界

同预算/回归方式的Oracle_ALL在18个分类路由中对应值严格相同。分类器差异只改变路由，不改变共享回归映射。
S_CC与Oracle_CC完全相同（正确路由子集）；不同分类器的S_CC子集不同，不能据此声称回归映射改善。
Oracle_ALL仅4个唯一bank，不能把重复的oracle结果作为3个独立回归seed计算显著性。
routing_excess_MSE = MSE(S_ALL) − MSE(Oracle_ALL) 是同一全集上的诊断；可能为负，错误路由偶然数值接近不等于语义正确。
浓度评价为预测气体通路的标量ppm误差，不惩罚气体身份本身；应同时阅读Accuracy与浓度误差，不以浓度误差取代分类正确性。

## 限制和停止

冻结source prior使用104D H1（包括21维协议/phase元数据）；源增强效应不能单独归因于纯浓度知识。
5%/20%固定窗口协议与原论文一致，未新增独立raw-file/设备划分；CV虽按raw filename分组，不改变最终测试独立性局限。
三seed只改变分类训练，回归bank及其alpha固定共享；没有新增bootstrap/p值、FULL、QC、其他target、训练或算法搜索。
结果保留负收益与气体异质性，不宣称完整FedOnGas/FULL优越；完成后停止。
