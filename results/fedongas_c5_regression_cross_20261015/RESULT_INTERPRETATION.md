# 科学解释：收益取决于预算、误差指标和气体

证据：`regression_summary_12.csv`、`paired_summary_22.csv`、`per_gas_summary_48.csv`、`paired_deltas_66.csv`、`oracle_unique_banks.csv`。
所有数值为本轮实际完成的36组固定流水线；不是新增神经网络训练或新的分类模型选择。

## 1. 同一分类器下，源定量参考是否有用？

按三seed的总体RMSE均值，6个“分类器×预算”组合的R84都低于83D；差值如下（ppm）：

|预算|TO：R84−83D|FT：R84−83D|CLASS：R84−83D|
|---|---:|---:|---:|
|5%|−0.19093|−0.17372|−0.17103|
|20%|−1.05645|−0.85132|−0.51947|

这支持**冻结源定量参考在当前协议下有小幅平均RMSE收益**，不支持“所有样本/seed/气体均受益”。例如CLASS、20%、seed42的R84 RMSE反而增加0.07539 ppm；其NRMSE增加0.00598。

真实类别路由、全部样本的Oracle_ALL：

|预算|83D RMSE|R84 RMSE|R84−83D|
|---|---:|---:|---:|
|5%|27.03495|26.71398|−0.32096|
|20%|19.77305|18.50709|−1.26596|

Oracle改善表明回归映射本身有平均收益，不仅来自不同分类路由。但4套bank是共享的，Oracle不能复制成三个独立回归seed。

数量澄清：总分类端点为18个（3分类器×2预算×3seed），而每一个固定“预算×回归方式”bank对应9条流水线（3分类器×3seed）。原自动报告中“同预算/方式在18个分类路由”是数量表述笔误，应为9；不涉及表格或指标错误。保留原冻结运行报告及其SHA，通过此说明勘误，不覆盖历史输出。

## 2. 历史分类知识是否值得复用？

5%下，平均RMSE排序为FT < CLASS < TO；20%下则TO < CLASS < FT，两个回归方式均如此。

相对TO+83D：

|预算|FT+R84 ΔRMSE（mean ± SD）|CLASS+R84 ΔRMSE（mean ± SD）|
|---|---:|---:|
|5%|−2.54011 ± 2.97174|−2.38785 ± 1.31938|
|20%|+3.05148 ± 3.15613|+0.01136 ± 0.76179|

因此，低标签预算下观察到知识复用流程的平均优势；20%下不支持其相对TO+目标Ridge的总体RMSE优势。20% CLASS+R84的+0.01136 ppm应解释为近似持平的点估计，而不是显著劣化。
5% FT+R84在seed42相对TO+83D仍差0.86823 ppm；不能把平均优势写成每seed稳定优势。

## 3. 分类准确率排序不一定等于最终浓度误差排序

本轮**总体RMSE**的三分类器均值排序恰好与Accuracy排序一致，不能据此声称已经观察到RMSE与Accuracy排序反转。
但5%下，FT的平均Accuracy最高（97.623%），CLASS+R84的NRMSE为0.21853，低于FT+R84的0.24061。
总体RMSE按ppm计误差，NRMSE按真实gas量程逐样本归一化，排序不同并不矛盾；报告时必须指定指标，不选择性只报有利指标。

## 4. 收益不是气体一致的

- Methane的R84平均RMSE在两预算、三分类器下均改善：5%约0.65–0.75 ppm，20%约1.70–3.31 ppm。
- CO：5%仅约0.04–0.05 ppm改善，20%反而约0.33–0.42 ppm变差。
- Ethylene：两预算三分类器均有轻微平均RMSE负迁移（增加约0.06–0.24 ppm）。
- Ethanol：方向依赖预算/分类器；不能用总体均值掩盖气体异质性。

逐gas完整mean/sample SD、MAE、NRMSE及配对差值均已保存。没有根据这些test结果重选alpha、改路由、调source权重、改特征或追加实验。

## 5. 可以与不可以写进论文的结论

可以写：在既定C5窗口划分下，冻结源参考增强有小幅平均总体RMSE改善，且低预算时历史分类知识复用的平均收益更明显；这种收益受预算和气体影响，并非普适优势。

不可以写：FULL/FedOnGas整体优于所有基线、类别–阶段机制已被本轮证明、CLASS改善了共享回归映射、每个seed/气体稳定受益，或三个seed构成统计显著证据。

分类器只改变路由；同预算/回归方式下映射完全共享。S_CC与Oracle_CC相同，且其子集随分类器变化。标量浓度误差也不等于气体身份识别正确性。
源参考使用104D H1（含21维协议/phase元数据），并非只用传感83D；因此源增强收益不能被单独归因于纯浓度先验。
本轮无FULL、QC、其他目标、神经网络训练、源回归重训或新算法搜索。结论仅限当前canonical-v1固定窗口协议。

最终描述性结论：**SOURCE_REFERENCE_AVERAGE_RMSE_BENEFIT_SUPPORTED_WITH_LIMITATIONS；CLASSIFICATION_REUSE_BENEFIT_BUDGET_DEPENDENT。**
