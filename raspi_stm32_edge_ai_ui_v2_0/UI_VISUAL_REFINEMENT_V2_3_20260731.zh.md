# GAPS 上位机 UI v2.3 视觉优化说明

## 目标

本轮只优化上位机的信息层级与视觉表达，保留原有三项核心能力：

1. 原始数据持续保存、分段保存与实验事件标记；
2. 16 通道实时曲线显示；
3. AI 类别、暴露共识、模型分数、QC、推理延迟和输入频率显示。

模型、归一化参数、推理结果和 Runtime v5 fail-closed 规则均未修改。

## 主要改动

- 使用深蓝仪器面板主题，以青绿色表示正常信号和主要操作，以琥珀色表示未验证或需人工关注状态；
- 小屏标签简化为 `Curve / Data / AI Reliability`，大屏显示
  `Sensor Curve / Data & Logs / AI Reliability`；
- 统计卡片按预测、可靠性、系统状态、环境和存储分组；
- 传感器曲线改用色盲友好通道色板，并优化坐标轴、网格和抗锯齿；
- AI 页面增加任务、输入来源和 QC 三个上下文徽标；
- 实验室模型显示为短身份 `LAB-S150 · P2→P3 · r3`；
- 回放包明确显示 `REPLAY INPUT`，避免与真实串口实时输入混淆；
- softmax 百分比改称 `Model Score`，高值显示为 `>99.9`，避免暗示绝对正确概率；
- 单窗口暴露共识以警示色显示，表明仍在累积；
- 800×480 推理完成后隐藏重复的详细进度，只保留六张核心卡片和主要操作；
- 大屏继续显示结果摘要、窗口进度和历史趋势图；
- 数据页继续保留连接、环境、存储、接收统计、实验事件和审计日志。

## 验证

- `compileall`：通过；
- UI 逻辑自测：通过；
- Runtime v5 fail-closed：通过；
- A4 classification-only PC UI：通过；

- 1440×900：显示完整 AI 历史趋势与数据记录面板；
- 最终 r3 模型包指纹保持为
  `88a4a4d75c6bd2f1a917a1e771712a0568e9c284bee599f4f83ab26257fb0877`。

## 视觉烟雾测试边界

曲线和数据页截图中的数值由视觉烟雾测试生成，只用于检查布局、颜色和控件可见性，不属于实验结果。正式运行仍只接受真实串口数据或显式标记的冻结回放输入。
